## .env.example

New contributors can't get the API and its tests running locally because nobody wrote
down the environment it needs. Add `app/.env.example` that lists every environment
variable a developer needs in order to build, run and test the API in this environment,
filled in with values that work. Look at your own environment to find them.

Add a short note in `app/README.md` saying to copy it to `app/.env`.
